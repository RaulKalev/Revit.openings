# Revit.openings

A Revit add-in for managing openings in BIM models.

## Overview

Revit.openings provides tools for creating, modifying, and managing openings (doors, windows, and structural penetrations) within Autodesk Revit projects.

## Prerequisites

- Autodesk Revit 2022 or later
- .NET Framework 4.8 or .NET 6+
- Visual Studio 2022 (for development)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/RaulKalev/Revit.openings.git
   ```
2. Open the solution in Visual Studio.
3. Restore NuGet packages.
4. Build the solution.
